👋 SignBridge Avatar Widget

Прозрачный виджет сурдопереводчика для встраивания

✨ Демо виджета

Виджет показывает только верхнюю часть тела (до пояса), как профессиональные сурдопереводчики.

🎭 Попробуйте интерактивность:

Выделите слова мышью:

hello idle

📦 Как встроить на свой сайт

Скопируйте этот код и вставьте в любое место вашей страницы:

<!-- 1. Подключите стили --> <link rel="stylesheet" href="/src/main.css"> <!-- 2. Создайте контейнер --> <div id="avatar-widget-container"></div> <!-- 3. Подключите скрипт --> <script type="module" src="/src/widget/index.js"></script>

⚙️ Основные возможности

  • ✅ Прозрачный фон
  • ✅ Портретная ориентация (как сурдопереводчик)
  • ✅ Интерактивные анимации при выделении текста
  • ✅ Адаптивный дизайн
  • ✅ Легкая настройка через config.js
  • ✅ Поддержка VRM/VRMA форматов

🎨 Настройка положения

Измените CSS для нужного расположения:

/* Правый нижний угол (по умолчанию) */ #avatar-widget-container { position: fixed; bottom: 20px; right: 20px; } /* Левый нижний угол */ #avatar-widget-container { position: fixed; bottom: 20px; left: 20px; } /* Встроенный виджет */ #avatar-widget-container { position: relative; display: inline-block; }
