Анализ функциональности JavaScript проекта signBridge-avatar
Проект представляет собой систему для работы с 3D аватарами формата VRM, предназначенную для перевода текста на жестовый язык и создания видеороликов.

1. Ядро системы (Утилиты)
Основные механизмы работы с 3D моделями и анимацией сосредоточены в папке src/utils:

vrm-loader.js
:
Загрузка VRM моделей с использованием @pixiv/three-vrm.
CC Bone Mapping: Специальная логика переименования костей (из формата Character Creator/Mixamo в стандарт VRM) для корректной работы анимации.
animation-loader.js
:
Загрузка файлов анимации формата .vrma.
Поддержка кэширования анимаций для оптимизации производительности.
json-animation-player.js
:
Позволяет создавать анимационные клипы (AnimationClip) на лету из кастомного JSON формата (содержащего данные о поворотах и позициях костей).
vrma-exporter.js
:
Сложная логика экспорта накопленных кадров в стандартный файл .vrma (Binary GLTF с расширением VRMC_vrm_animation).
2. Студия (src/studio)
Инструмент для создания видео-контента с аватаром.

Управление сценой: Настройка освещения, камеры и заднего фона (зеленый экран, белый, любой цвет или произвольное изображение).
Работа с глоссами: Пользователь вводит последовательность слов (глосс), а система автоматически собирает их в единую анимационную последовательность.
Таймлайн: Визуальное отображение последовательности анимаций с возможностью перехода (seek) к конкретному моменту.
Видеозапись:
Использование MediaRecorder API для захвата потока из WebGL.
Поддержка различных форматов (WebM/MP4) в зависимости от браузера.
Настройка качества (480p, 720p, 1080p) и соотношения сторон (16:9, 4:3, 1:1).
3. Виджет (src/widget)
Компактная версия аватара для интеграции на сайты.

Режимы отображения: Компактный (в углу экрана) и развернутый.
Text Selection Trigger: Ключевая особенность — при выделении текста мышкой на любой части страницы, виджет перехватывает это событие, ищет совпадения в списке анимаций и автоматически воспроизводит соответствующий жест.
Плавные переходы: Использование кроссфейдов (crossfade) для мягкого перехода от состояния покоя (idle) к жестам.
4. Конфигурация (src/config.js)
Единое место для настройки:

Списка доступных аватаров и путей к их файлам.
Списка доступных анимаций (жестов).
Стандартных настроек камеры и света.
Параметров Motion Capture (подготовка к использованию MediaPipe).
Основные технологии:
Three.js: Основа для 3D рендеринга.
@pixiv/three-vrm: Стандарт для работы с VRM.
MediaRecorder API: Для создания видео.
