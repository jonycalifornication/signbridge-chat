# Руководство по Backend S3 и интеграции Yandex Cloud

## 1. Какой нужен бэкенд для S3?

Когда речь идет об S3 (Simple Storage Service), "бэкендом" выступает само **облачное хранилище объектов**. Вам не нужно писать отдельный сервер для хранения файлов.

В вашей архитектуре роль S3 бэкенда выполняет сервис **Yandex Object Storage**.

Ваш основной бэкенд (FastAPI/Python) будет выступать лишь в роли "контроллера":
1.  **Генерация ссылок**: Бэкенд сообщает фронтенду, по какому URL скачать нужную анимацию.
2.  **Загрузка контента**: Администратор загружает новые файлы через скрипты или админку, а бэкенд сохраняет их в S3.
3.  **Безопасность**: Бэкенд хранит секретные ключи доступа, чтобы не светить их на клиенте.

**Технический стек для работы с S3:**
*   **Сервис**: Yandex Object Storage.
*   **Библиотека (Python)**: `boto3` (стандарт индустрии для работы с S3-совместимыми хранилищами) или `aioboto3` (для асинхронной работы в FastAPI).

## 2. Реализация на Yandex Cloud (Пошагово)

### Шаг 1: Подготовка в консоли Yandex Cloud

1.  **Создайте бакет (Bucket):**
    *   Зайдите в консоль Yandex Cloud -> **Object Storage**.
    *   Нажмите **Создать бакет**.
    *   **Имя:** `signbridge-animations` (например). *Имя должно быть уникальным во всей системе Yandex*.
    *   **Максимальный размер:** Можно оставить пустым (без ограничений).
    *   **Доступ:** `Ограниченный` (рекомендуется) или `Публичный` (если готовы раздавать файлы всем напрямую без проверок). *Для High Load с CDN лучше начать с публичного на чтение или настроить Bucket Policy.*
    *   **Класс хранилища:** `Стандартное` (для частого доступа).

2.  **Создайте сервисный аккаунт (Service Account):**
    *   Перейдите в раздел **Сервисные аккаунты**.
    *   Создайте новый аккаунт, например `s3-uploader`.
    *   Выдайте роль: `storage.editor` (для загрузки и удаления) или `storage.viewer` (только чтение).

3.  **Получите статические ключи доступа:**
    *   Зайдите в созданный сервисный аккаунт.
    *   Нажмите **Создать новый ключ** -> **Создать статический ключ доступа**.
    *   Сохраните **Key ID** и **Secret Key**. *Secret Key показывается только один раз!*

### Шаг 2: Настройка CORS (Критично для Web-виджета)

Так как ваш виджет (`JS`) будет загружать файлы напрямую из S3 (или через CDN) в браузер с другого домена, нужно настроить CORS (Cross-Origin Resource Sharing).

1.  В консоли Object Storage выберите ваш бакет.
2.  В меню слева выберите **CORS**.
3.  Нажмите **Настроить**.
4.  Добавьте правило:
    *   **Allowed Origins (Разрешенные источники):** `*` (для разработки) или ваш домен `https://your-site.com`.
    *   **Allowed Methods (Разрешенные методы):** `GET`, `HEAD`.
    *   **Allowed Headers (Разрешенные заголовки):** `*`.
    *   **Max Age:** `3600`.

### Шаг 3: Интеграция с Python (FastAPI)

Установите библиотеку:
```bash
pip install boto3
# или для асинхронности
pip install aioboto3
```

**Пример кода (синхронный boto3):**

```python
import boto3
from botocore.exceptions import NoCredentialsError

# Конфигурация
AWS_ACCESS_KEY_ID = 'ВАШ_KEY_ID'
AWS_SECRET_ACCESS_KEY = 'ВАШ_SECRET_KEY'
REGION_NAME = 'ru-central1'
ENDPOINT_URL = 'https://storage.yandexcloud.net'
BUCKET_NAME = 'signbridge-animations'

# Инициализация клиента
s3_client = boto3.client(
    's3',
    aws_access_key_id=AWS_ACCESS_KEY_ID,
    aws_secret_access_key=AWS_SECRET_ACCESS_KEY,
    region_name=REGION_NAME,
    endpoint_url=ENDPOINT_URL
)

def get_file_url(filename):
    """Генерация публичной ссылки (если бакет публичный)"""
    return f"{ENDPOINT_URL}/{BUCKET_NAME}/{filename}"

def generate_presigned_url(filename, expiration=3600):
    """Генерация временной подписанной ссылки (если бакет приватный)"""
    try:
        response = s3_client.generate_presigned_url('get_object',
                                                    Params={'Bucket': BUCKET_NAME,
                                                            'Key': filename},
                                                    ExpiresIn=expiration)
        return response
    except NoCredentialsError:
        return None
```

### Шаг 4: Настройка CDN (Для High Load 1000+ пользователей)

Как указано в ТЗ, раздавать файлы напрямую с S3 может быть дорого и медленно для удаленных регионов. Используйте Yandex Cloud CDN.

1.  В консоли Yandex Cloud перейдите в **Cloud CDN**.
2.  Создайте **CDN-ресурс**.
3.  **Источник контента:** Выберите "Бакет Object Storage" и укажите ваш бакет.
4.  Свяжите с доменным именем (например, `cdn.yoursite.com`), если есть, или используйте технический домен.
5.  В коде Python теперь отдавайте ссылки вида: `https://cdn.yoursite.com/filename.glb` вместо прямой ссылки на S3.

## Резюме
Для старта вам нужно:
1.  Создать Бакет в Yandex Cloud.
2.  Получить ключи доступа.
3.  Написать простой сервис на Python с `boto3` для управления файлами.
4.  Включить CORS, чтобы браузер не блокировал загрузку 3D-моделей.
